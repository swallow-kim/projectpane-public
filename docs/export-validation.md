## 실패와 실행 환경

초기 제한된 실행 환경의 Rust 시험은 254건 통과·54건 실패·14건 제외였습니다. 합성 임시 파일의 핸들·저널 접근에 AccessDenied가 반복됐습니다. 보안 설정을 바꾸지 않고 같은 소스를 일반 사용자 실행 환경에서 한 번 비교한 결과 308건이 통과했습니다. 초기 실패 기록은 공개 소스 외부에 보존했으며 통과로 덮어쓰지 않았습니다.

브라우저 worker가 종료된 뒤 시험용 Vite 서버 정리가 멈췄습니다. 로그의 PID와 시작 시각으로 소유권을 확인한 해당 서버만 종료한 후 254건 통과 결과와 종료 코드 0을 받았습니다. 제품 창·다른 사용자 프로세스는 종료하지 않았고 assertion 변경이나 재실행은 없었습니다. 브라우저 정리의 환경상 한계를 남깁니다.

## 제외한 범위

14개 Rust 시험은 명시적 다른 볼륨·WSL·휴지통 fixture가 필요한 opt-in 시험입니다. 실행하지 않았습니다. 실제 IME·Explorer·사용자 클립보드·설치/업데이트·새 장시간 메모리/soak 검사도 수행하지 않았습니다. Windows 11을 검증했다고 주장하지 않습니다. 일반 메모리 조건과 대용량 반복 사용의 알려진 제한은 [검증 범위](validation.md)에 유지합니다.

Git 이력, 개발 작업 기록, 개인 감사 자료, 스크린샷, CI 원본, 과거 측정 파일과 기존/신규 바이너리는 공개용 폴더에 포함하지 않습니다. 제품 아이콘 3개만 유지합니다. GitHub workflow도 포함하지 않습니다. 새 바이너리의 공개 배포는 [고지·패키지 요구사항](distribution.md)을 별도로 충족해야 합니다.

자동 검사는 발견하지 못한 비밀이나 제3자 권리 문제가 전혀 없다는 보장이 아닙니다. 제3자 고지를 유지하며 공개 목적지·파일 범위 승인을 받기 전 게시하지 않습니다.
