# UI 규칙

1.2.1의 목표는 파일 목록 공간과 일관된 키보드 조작입니다.

- Windows 기본 창틀과 어두운 앱 테마를 유지합니다. custom titlebar는 사용하지 않습니다.
- 프로젝트는 상단 탭으로 전환합니다. 상시 안내·시험 문구·작업 로그 행은 두지 않습니다.
- 패널 헤더는 폴더 탭·탐색/주소 행과 필터·작업 아이콘 행으로 구성합니다. 긴 경로·많은 탭·좁은 패널은 말줄임과 행 내부 가로 스크롤을 사용합니다.
- 파일 목록은 26px 고정 행, 파일명은 12px입니다. 전체 경로는 주소와 툴팁에서 확인합니다.
- 파일명 필터·모달·주소 입력과 목록 단축키의 포커스 범위를 분리하고 IME 조합을 가로채지 않습니다.
- 모든 선택 행은 같은 배경과 왼쪽 표식으로 표시합니다. 키보드 포커스는 별도 얇은 테두리로 구분합니다.
- 패널 경계는 중립색이며 hover 시 파란 막대로 번쩍이지 않습니다. resize cursor와 최소 focus-visible 표시를 유지합니다.
- 아이콘 버튼에는 접근성 이름·툴팁·비활성 상태를 제공합니다. 장식 애니메이션보다 목록 반응을 우선합니다.
- 진행·취소·결과는 작은 상단 파일 작업 버튼에서 열고 실패·확인 필요 상태를 숨기지 않습니다.
- Windows 11·Snap·DPI·실제 IME·보조기술의 실기 확인을 브라우저 합성 검사로 대체하지 않습니다.
