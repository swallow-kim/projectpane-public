# 외부 이동의 제품 경계

외부 Explorer 잘라내기·MOVE 프로토콜의 실행기·저널·보호 코드는 시험 전용입니다. 제품에서 활성화하지 않습니다. 앱 내부에서 지원하는 이동과 별개입니다.

시험 구현은 원본·대상 핸들 보호, 같은 볼륨 NTFS의 제한된 rename, 중복 실행 차단과 결과 불명 기록을 사용합니다. 외부 COM 호출의 timeout은 호출 취소를 의미하지 않으며, timeout 뒤 완료 통지나 원본 삭제를 재시도하지 않습니다.

영구 정지 COM을 격리하는 제품용 호스트 수명·마샬링·정상 종료·수동 복구 UX와 실제 Explorer 상호운용 검증은 남아 있습니다. 시험용 자식 프로세스의 종료 검사를 제품의 COM 복구 완료로 주장하지 않습니다. Windows↔WSL 이동도 활성화하지 않습니다.

현재 지원되는 파일 작업과 실패 시 안내는 [사용 안내](user-guide.md), 검증 한계는 [검증 문서](validation.md)를 따릅니다.
