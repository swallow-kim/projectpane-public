# ProjectPane 1.4.0 사용·복구 안내

현재 소스의 사용 안내입니다. 실제 게시된 파일은 GitHub Releases에서 확인하고, [설치·빌드](distribution.md)와 [지원 범위·검증 한계](validation.md)를 확인하세요.

## 업데이트

상단 **업데이트**에서 새 버전을 확인합니다. 앱 시작 후에도 하루 한 번 비동기로 확인하지만 자동으로 설치하지 않습니다. 설치형에서는 **다운로드**, 서명 검증 완료 후 **설치 후 다시 시작**을 각각 선택합니다. 파일 작업이 진행 중이면 완료 대기 또는 정상 취소를 선택하고, 현재 작업 공간을 프로젝트로 저장해야 재시작 복원을 확인할 수 있습니다. 저장 실패나 worker 종료가 불확실하면 설치를 중단합니다.

1.2.1 이하에서는 updater 지원판을 한 번 수동 설치해야 합니다. ZIP판 또는 설치 경로를 확인하지 못한 실행은 릴리스 페이지 안내만 제공합니다. 다운로드 취소는 이미 실행한 파일 작업을 되돌리는 Undo가 아닙니다. [업데이트의 실패·복구·서명 안내](updater.md)를 참고하세요.

## 목록에서 필터 입력 및 새 탭·패널

파일 목록에 포커스를 두고 글자를 입력하면 해당 패널의 파일명 필터에 첫 글자가 한 번 입력되고 포커스가 옮겨집니다. 이후에는 일반 입력칸처럼 입력·수정합니다. 목록에서 다시 타이핑하면 기존 필터에 덧붙이지 않고 **새 검색어로 교체**합니다. 기존 필터를 이어 편집하려면 필터 칸을 직접 선택하세요. 별도의 문자 선택 이동은 적용하지 않으며 이름 포함 여부와 정렬은 기존 파일명 필터 규칙을 따릅니다.

필터 칸에서 **Esc**를 누르면 필터를 비우고 해당 파일 목록으로 돌아옵니다. 결과가 없을 때도 목록에 포커스를 두고 새 검색어를 입력할 수 있습니다. 목록의 Space는 기존 선택 동작을 유지합니다. 주소·이름변경·다른 입력칸·대화상자, IME 조합 중 입력, Ctrl/Alt/Meta 조합을 가로채지 않습니다. 한글 조합은 필터 칸에서 직접 입력하세요. 조합 도중 Esc는 가로채지 않으며 실제 한글 IME는 아직 미검증입니다.

프로젝트에서 새 탭(+ 또는 Ctrl+T)을 열면 프로젝트 루트를 사용합니다. 1→2/4패널로 늘릴 때 빈 패널만 루트에서 시작하고 기존 패널의 경로는 유지합니다. 닫은 탭 복원·즐겨찾기에서 고른 경로·저장된 프로젝트 복원은 해당 경로를 유지합니다. 프로젝트가 없는 임시 공간은 기존 빈 탭 동작을 유지합니다. 루트 접근 실패 시 다른 폴더로 바꾸지 않고 해당 주소에 오류를 표시합니다.

## Phase 1 사용 방법

아래 기능은 1.1.0부터 제공합니다. [단계별 계획·검증 기록](post-v1-phases.md)을 참고하세요.

- **영역 선택:** 마지막 파일 아래 빈 공간이나 목록 오른쪽의 12px 여백에서 누른 채 파일 행 쪽으로 끕니다. Ctrl은 겹친 항목을 토글하고 Shift는 기존 선택에 더합니다. 위·아래 가장자리에 머무르면 자동 스크롤합니다. 파일 행에서 시작하면 기존 파일 드래그가 됩니다. Esc, 창 포커스 상실, 탭/목록 갱신은 영역 선택을 취소합니다. 빈 곳을 그냥 클릭하면 선택을 해제합니다.
- **빠른 이동:** 상단 버튼 또는 Ctrl+Shift+P로 열고 검색한 뒤 위·아래 방향키와 Enter로 실행합니다. Esc로 닫으면 이전 포커스로 돌아갑니다. 프로젝트·현재 작업 공간의 열린 탭·공통 즐겨찾기·열린 탭들의 최근 탐색 이력·탐색 명령을 검색합니다. 최근 폴더는 최대 32개이며 결과는 최대 100개입니다. 검색어를 좁히면 뒤쪽 항목도 찾을 수 있습니다. 디스크 검색이나 다른 프로젝트의 저장 세션 검색은 하지 않습니다. 숨긴 패널의 탭을 고르면 해당 패널도 다시 표시합니다.
- **닫은 탭 복원:** Ctrl+Shift+T 또는 굽은 화살표 버튼으로 패널별 최근 10개·총 64KiB 이내의 경로와 정렬·필터를 복원합니다. 이전 선택·스크롤·탐색 이력은 복원하지 않고 새 탭으로 엽니다. 32탭이 이미 열려 있으면 먼저 하나를 닫으세요. 폴더가 사라졌다면 오류를 표시한 탭의 주소를 수정하거나 닫을 수 있습니다.
- **탭 닫기 보호:** 자물쇠 버튼은 현재 탭의 X·Ctrl+W 닫기를 막습니다. 다시 누르면 해제합니다. 폴더 탐색을 고정하거나 파일 수정을 막는 기능은 아닙니다. 보호와 닫은 탭 이력은 현재 작업 공간에서만 유지하며 프로젝트 전환·프리셋 복원·앱 종료 시 초기화됩니다. 기존 프로젝트 저장 파일 형식은 바뀌지 않습니다.

팔레트에서 폴더를 고르면 현재 패널의 경로가 바뀌며 파일 복사·이동은 실행하지 않습니다. 없는 폴더·연결이 끊긴 공유 폴더는 기존 탐색 오류로 표시하고 즐겨찾기를 지우지 않습니다. 물리 한국어 IME와 회사 Windows 11 입력은 별도 미검증입니다.

## 화면과 폴더 열기

상단에서 1·2·4패널을 선택하고 프로젝트 탭으로 작업 공간을 전환합니다. 각 패널은 **폴더 탭+탐색/주소**, **필터+작업 아이콘** 두 줄입니다. 아이콘에 마우스를 올리면 설명을 볼 수 있으며 키보드 포커스와 접근성 이름도 제공합니다. 좁은 패널의 도구 행과 많은 폴더 탭은 가로 스크롤합니다.

주소 필드에 전체 경로를 입력하고 Enter 또는 이동 아이콘을 누릅니다. 긴 경로도 필드를 선택해 확인·편집할 수 있습니다. 파일 목록은 26px 행과 12px 글자를 사용하며 이름·유형·크기·수정한 날짜를 표시합니다. 부분 목록 안내가 있으면 표시되지 않은 파일이 있을 수 있습니다. Windows 기본 제목표시줄을 유지하고 앱과 어두운 테마를 맞췄습니다.

패널 경계에 마우스를 올리면 크기 조절 커서가 표시됩니다. 경계를 드래그해 비율을 바꾸며 눈에 띄는 hover 막대는 없습니다. 키보드로 경계에 포커스를 두면 얇은 표시와 함께 방향키·Home·End로 조절합니다. Esc는 진행 중인 조절을 멈추고 현재 비율을 유지합니다.

## 폴더 즐겨찾기

- 현재 주소 옆 **별** 버튼으로 폴더를 등록하거나 해제합니다. **폴더 즐겨찾기 열기** 아이콘에서는 현재 패널의 폴더를 바꾸거나 **새 탭**으로 엽니다.
- 상단 **즐겨찾기 관리**에서는 이름·절대 경로로 추가하고, 기존 이름/경로를 수정하거나 해제합니다. 목록은 프로젝트 공통이며 정상 저장 후 재시작해도 유지됩니다. 최대 128개이며 정규화한 경로의 대소문자 차이 등 중복을 막습니다. 링크·별칭이 가리키는 동일 폴더까지 판별하는 기능은 아닙니다.
- 복사·이동 대화상자의 **즐겨찾기 대상 폴더**는 목적지 입력을 채웁니다. 선택만으로 실행하지 않습니다. 복사는 **복사** 한 번으로, 이동은 **대상 확인 → 실행**으로 진행합니다. 외부 잘라내기·이동을 활성화하는 기능도 아닙니다.
- 없는 폴더·끊긴 네트워크 경로·권한이 없는 경로는 탐색 시 오류를 표시하고 즐겨찾기에서 자동 삭제하지 않습니다. 연결/권한을 확인하거나 관리 창에서 경로를 수정·해제하세요.
- 저장 실패 또는 응답 불명 안내가 나오면 **다시 불러오기**로 실제 저장 상태부터 확인합니다. 앱은 변경을 자동으로 재전송하지 않으며 저장 확인 전 정상 종료를 완료 처리하지 않습니다. 손상된 즐겨찾기 파일은 그대로 보존합니다.

## 프로젝트 저장과 다시 열기

1. 각 패널의 주소에 작업할 폴더를 입력하고 패널 배치와 탭을 구성합니다.
2. 상단 **프로젝트 관리**를 펼치고 **새 프로젝트**에서 이름과 기준이 될 루트 폴더를 입력한 뒤 **만들기**를 누릅니다. 현재 화면 구성이 프로젝트의 초기 프리셋이 됩니다.
3. 이후 작업 상태는 자동 저장됩니다. 상단의 **마지막 작업 상태 저장됨**을 확인하세요. **임시 작업 공간 · 자동 저장 안 함**이면 프로젝트에 연결되지 않은 상태입니다.
4. 프로젝트 탭으로 다른 프로젝트를 엽니다. 긴 이름은 말줄임/툴팁으로 확인하고 탭이 많으면 가로 스크롤합니다. 좌우 방향키·Home·End로 탭 포커스를 옮기고 Enter·Space로 전환합니다. 폴더 인자 없이 다시 실행하면 저장된 마지막 프로젝트를 복원합니다. 강제 종료 직전의 미저장 변경까지 보존하는 것은 아닙니다.

**프로젝트 편집**에서 이름과 루트 경로를 수정합니다. 기존 탭과 프리셋에 저장된 실제 폴더 위치는 유지하며 파일을 이동하지 않습니다. 이후 새 탭과 빈 패널은 변경된 루트를 기본으로 엽니다. 주소에 `src`나 `..\shared` 같은 상대경로를 입력하면 현재 폴더가 아니라 프로젝트 루트 기준으로 해석합니다.

**현재 상태를 프리셋으로 저장**은 기본 구성을 명시적으로 바꿉니다. **프리셋 복원**은 현재 화면을 그 기본 구성으로 바꿉니다. 자동 저장하는 마지막 세션과 프리셋은 별개입니다. **복제**는 프로젝트 설정만 복제하며 실제 파일을 복사하지 않습니다. **목록에서 제거**도 실제 파일을 삭제하지 않습니다.

## 키보드와 Windows 연동

Ctrl+클릭은 선택을 추가/해제하고 Shift+클릭은 기준 항목부터 범위를 선택합니다. 선택된 모든 행은 동일한 배경과 왼쪽 표식을 유지하며, 현재 키보드 포커스만 얇은 테두리로 구분합니다. 다른 패널에 포커스를 옮겨도 선택 강조가 남습니다. 여러 파일 작업 전 선택 개수와 대상 폴더를 확인하세요. 이동·휴지통 확인창에서는 원본 목록도 확인합니다.

| 키/동작 | 기능 |
| --- | --- |
| Ctrl+L, F6/Shift+F6 | 현재 패널 주소 선택, 다음/이전 패널 주소로 이동 |
| Alt+←/→/↑, F5 | 뒤로/앞으로/상위 폴더, 새로 고침 |
| Home/End, 방향키, PageUp/PageDown | 목록 위치와 선택 이동 |
| Ctrl+A, Ctrl·Shift+클릭 | 전체 선택, 선택 토글·범위 선택 |
| Ctrl+C, Ctrl+V | Windows 복사, 현재 폴더에 바로 붙여넣기 |
| Ctrl+X | 앱 내부 잘라내기. 유효한 내부 잘라내기는 Ctrl+V로 대상 확인 |
| Ctrl+Shift+C, Ctrl+Shift+V | 앱 안에 복사 담기, 앱에 보관한 항목 붙여넣기 |
| F2, Delete, Alt+Enter | 이름 변경, 일반 파일 휴지통 이동 확인, 단일 항목 Windows 속성 |
| Shift+F10, 메뉴 키 | 선택 항목의 앱 메뉴 |

파일 작업 단축키는 파일 목록에 포커스가 있을 때 사용합니다. 주소·필터의 텍스트 복사/붙여넣기와 IME 조합은 가로채지 않습니다. 새로고침 중에는 이전 목록에 대한 작업을 잠시 막습니다. Esc는 상황에 따라 메뉴/대화상자 닫기, 진행 중 선택 취소, 앱 내부 보관 해제 또는 현재 조회 취소를 처리합니다.

Ctrl+X는 Windows 클립보드에 외부 잘라내기를 게시하지 않습니다. Windows 클립보드가 변경되면 오래된 내부 잘라내기를 취소하고 안내합니다. 이때 같은 Ctrl+V를 자동 재실행하지 않으며, 다시 누르면 Windows에서 붙여넣기를 요청합니다.

일반 우클릭은 앱 메뉴이며 선택된 여러 항목 위에서는 선택을 유지합니다. **탐색기에서 선택 항목 보기**는 기본 탐색기로 이동하는 대안입니다. **Windows 메뉴 (시험)**는 Windows Shell 메뉴를 명시적으로 요청하며 확장 프로그램 전체의 호환을 보장하지 않습니다. Shell 메뉴에서 실행한 명령은 Windows에 위임되며 앱의 작업 로그·복구 보장과 별개입니다.

패널 사이 드래그는 대상 패널에 바로 복사하고, Shift+드래그는 앱 내부 이동 확인창을 엽니다. 외부 드롭은 실제 파일·폴더의 복사만 내부 검증 후 실행합니다. 외부 잘라내기/이동·우클릭 드래그·가상 파일·Shell namespace·재분석 지점 전송은 지원하지 않습니다. 실제 Explorer 물리 왕복과 사용자 클립보드 시험은 미검증입니다.

## 경로 텍스트 복사

파일이나 폴더를 우클릭하고 **절대경로 복사** 또는 **상대경로 복사 (프로젝트 루트 기준)**를 고릅니다. 예를 들어 프로젝트 루트가 `C:\작업`, 현재 폴더가 `C:\작업\문서`이면 `한글.txt`의 상대경로는 `문서\한글.txt`입니다. 프로젝트가 없는 임시 공간에서는 기존처럼 현재 폴더를 기준으로 합니다. 메뉴에 마우스를 올리면 기준 폴더 전체를 확인할 수 있습니다.

여러 선택 항목 위에서 우클릭하면 선택을 유지하고 경로를 한 줄씩 복사합니다(최대 128개). 빈 곳에서는 경로 복사가 비활성입니다. 이 기능은 **텍스트 복사**이며 파일을 복사·이동하지 않습니다. 성공하면 이전 앱 내부 잘라내기 보관을 해제합니다. 기준이 없거나 다른 드라이브/공유 등 기준 폴더와 맞지 않는 경로는 상대경로로 꾸미지 않고 오류를 표시합니다.

완료 문구를 확인한 뒤 텍스트를 붙여넣으세요. 클립보드 오류나 성공 미확인 응답에는 성공 문구를 띄우지 않으며 자동 재시도하지 않습니다. Windows가 클립보드를 비운 뒤 쓰기에 실패하면 이전 내용을 보존·복구할 수 있다고 보장하지 않습니다. 검증 범위는 실제 사용자 클립보드를 바꾸지 않는 모의/메모리 검사와 구분합니다.

## 저장 실패와 손상된 설정

- 저장 실패가 표시되면 현재 창을 유지하고 저장 위치의 접근 권한·디스크 여유 공간을 확인한 뒤 **다시 시도**를 누릅니다. 종료 전 저장 실패나 시간 초과 때는 창을 유지합니다. 닫기 실패 후 파일 작업이 중단된 상태라면 프로젝트 저장을 마치고 앱을 정상적으로 다시 실행하세요.
- 복구한 문서는 **읽기 전용**으로 열리고 자동 저장이 차단됩니다. 내용을 확인한 뒤 **현재 상태를 새 프로젝트로 저장**을 누르면 별도 프로젝트로 저장할 수 있습니다. 원본 문서와 백업은 보존됩니다.
- 지원하지 않는 미래 버전이나 복구할 수 없는 문서는 목록에서 빠지거나 경고가 표시될 수 있습니다. 새 버전 형식을 직접 낮추거나 원본 JSON을 덮어쓰지 마세요. 아래 방법으로 현재 데이터를 복사해 보존하고 오류 문구를 함께 전달하세요.
- USB 등 폴더가 사라졌을 때 주소는 남겨 둡니다. 장치를 다시 연결하고 새로 고침하거나 사용할 폴더를 직접 선택하세요. 프로젝트 복원은 삭제된 실제 파일을 복구하는 기능이 아닙니다.

## 이름과 확장자 변경

파일 하나에서 F2를 누르면 이름과 확장자를 따로 입력합니다. 처음에는 이름만 선택되며 최종 파일명을 바로 보여줍니다. 폴더는 이름 칸 하나입니다. `.env`는 이름으로 유지하고 `.tar.gz` 같은 일반적인 복합 확장자는 함께 표시합니다. 확장자 없는 파일에 새 확장자를 넣을 수도 있습니다.

이름만 바꾸면 Enter/실행으로 바로 처리합니다. 확장자를 바꾸거나 비우면 한 번 더 확인합니다. **확장자를 바꿔도 파일 내용이나 형식이 변환되지 않습니다.** 별도 유지/변경/삭제 모드는 없습니다. Tab으로 입력칸을 이동하고 Esc로 취소합니다. Windows 금지 이름·경로 문자·끝 공백/점과 중복 대상은 거부합니다. 대소문자만 바꾸는 이름 변경도 지원합니다.

## 대용량 복사의 보존 범위

**복사 작업**에서 진행과 결과를 열고 **복사 취소**를 요청할 수 있습니다. 결과는 **다음 복사 결과**로 나누어 확인합니다. 선택 항목 진행과 처리 기록 수는 다릅니다. 폴더 생성과 최종 속성 적용은 별도 기록이므로 처리 기록 수를 파일 수로 해석하지 마세요. 창을 닫아도 진행 중 작업은 취소되지 않습니다. 앱 종료 시에는 완료를 기다리거나 정상 취소를 선택해야 합니다.

파일의 DATA 대체 스트림(ADS, 예: 다운로드 출처 Zone.Identifier)은 대상이 지원할 때 보존합니다. ADS가 있는 원본을 ADS 미지원 대상으로 복사하면 해당 파일 생성 전에 거부하며, ADS를 버리고 복사하는 대체 동작은 없습니다. 링크·재분석 지점·특수 파일 등 지원하지 않는 항목은 거부합니다. 기본 시간·일반 속성 보존이 모든 Windows/Linux 보안 정보·소유권·확장 속성 보존을 뜻하지는 않습니다.

취소·실패 뒤 이미 완료되거나 일부 생성된 대상은 남을 수 있습니다. 원본은 삭제하지 않으며 자동 재시도·전체 되돌리기를 하지 않습니다. 결과 기록이 불완전하거나 상태를 확인하지 못하면 원본과 대상을 직접 비교한 뒤 다음 작업을 결정하세요. 실제 원격 NAS는 검증하지 않았습니다. [현재 검증 결과와 제한](large-copy-validation-20261109.md)을 참고하세요.

## 파일 작업 결과 확인

복사 전 선택 항목과 대상 폴더를 확인하세요. 일반 붙여넣기·복사 드롭은 내부 검증 뒤 바로 접수하며, 목적지 선택이 필요한 복사는 **복사** 한 번으로 실행합니다. 중복 경로 확인창은 표시하지 않습니다. 경로·권한·충돌·원본 변경 검사는 계속 적용하고 기존 파일을 덮어쓰지 않습니다. 복사는 **상단 복사 작업 버튼**, 그 밖의 작업은 **상단 파일 작업 버튼**에서 진행·취소·결과를 확인합니다. 상시 패널은 없으며 결과 창을 닫으면 파일 목록 공간을 그대로 사용합니다. 실패나 취소 뒤에는 **파일 작업 결과**의 전체 판정과 각 항목을 함께 확인합니다. 항목별 불명 수가 0이어도 전체 완료·취소 여부가 불명일 수 있으며, 버튼에도 진행/확인 필요 건수를 표시합니다.

이동·확장자 변경 등 확인이 남아 있는 미리보기의 **조건 변경**을 누르면 이전 확인을 취소하고 경로·이름을 수정할 수 있습니다. 입력값은 유지되며 **대상 확인**을 다시 거쳐야 실행됩니다. 취소에 실패했다는 안내가 나오면 조건 변경을 다시 누르거나 창을 닫으세요.

**결과 불명**이면 원본과 대상의 실제 내용부터 확인하세요. 앱은 불명 작업을 자동으로 다시 실행하지 않습니다. 취소는 이미 복사·이동한 항목을 원래대로 되돌리는 기능이 아닙니다. **기록 정리**는 종료·저장이 확인된 앱 기록만 지우며 실제 파일을 삭제하거나 작업을 취소하지 않습니다.

**기록 미저장 상태로 닫기**가 제공되는 경우에는 실행기의 종료가 확인됐지만 결과 기록을 저장하지 못한 상태입니다. 이 선택으로 닫으면 다음 실행에서 실제 변경 여부를 직접 확인해야 합니다. 경고를 확인하기 전에는 창을 유지하세요.

새 폴더·이름 변경·파일/폴더 복사를 지원하며, 일반 파일 이동과 같은 드라이브 폴더 이동은 미리보기·원본 검증 후 실행합니다. 일반 파일 복사·붙여넣기·복사 드롭에서 같은 이름이 있으면 충돌 창에서 기존 파일 건너뛰기 또는 파일 하나를 다른 이름으로 복사하기를 선택합니다. 복사 당시의 원본 선택을 유지하며 재선택하거나 Windows 클립보드를 다시 읽지 않습니다. 폴더 병합·덮어쓰기는 지원하지 않습니다. 1.4.0 복사는 선택과 결과를 디스크에 나누어 기록하고 폴더를 순차 탐색합니다. 이전 128/1,024개 선택·2,048개 하위 결과의 총 개수 한도는 적용하지 않습니다. 개별 요청의 크기와 경로·파일 형식 검사는 유지하며 링크와 기존 대상 덮어쓰기는 거부합니다.

다른 드라이브의 폴더 이동은 **양쪽 모두 로컬 고정 NTFS**, 최대 2,048항목의 일반 폴더 트리에 한정합니다. 링크·암호화·오프라인 파일·하드링크·폴더 자체의 추가 데이터 스트림(ADS)은 거부하며, 서로 다른 이동 방식을 섞은 선택은 나눠 실행하세요. 파일의 ADS와 다운로드 출처는 Windows Shell 이동으로 보존합니다. 작업 중 다른 앱에서 원본이나 목적지를 수정하지 마세요. 변경을 감지하면 중단하지만, 임의의 동시 편집에 대한 원자적 트랜잭션이나 전체 되돌리기는 제공하지 않습니다. 취소·오류 시 일부 항목은 목적지로 이동하고 나머지는 원본에 남을 수 있습니다. 결과의 두 경로를 확인하고 남은 항목만 다시 선택하세요. 불명 작업은 자동 재실행하지 않습니다.

덮어쓰기·폴더 휴지통·영구 삭제는 지원하지 않습니다. 휴지통은 확인 창을 통한 고정 드라이브의 일반 파일에 한정하며 Shift+Delete를 영구 삭제로 제공하지 않습니다. 외부 MOVE의 실행기·저널·보호 기반은 시험용이며 제품에서 비활성입니다. 파일 작업의 기존 검증 범위, Windows 연동, Shell 메뉴의 한계를 구분해 참고하세요.

## ZIP 압축·해제 (미배포 개발 변경)

- 항목 하나 또는 여러 개를 선택하고 우클릭 → **압축하기…**를 누릅니다. 기본값은 **Windows 기본 ZIP**이며 현재 폴더에 새 ZIP을 만듭니다. ZIP 하나에서 **압축 해제…**를 누르면 현재 폴더 아래 새 폴더에 풉니다. 기존 출력은 덮어쓰거나 합치지 않습니다.
- 기본 ZIP은 일반 파일/폴더, ASCII 또는 UTF-8 이름, store/deflate, 최대 2,048항목·1GiB(원본/해제 총량, ZIP 크기), 깊이 64를 지원합니다. 암호화, ZIP64, 링크, 경로 탈출, Windows에서 충돌하는 이름과 손상 CRC는 거부합니다. 압축 파일 내부 탐색은 제공하지 않습니다.
- Windows PowerShell 5.1과 .NET ZIP 기능을 사용합니다. 회사 정책이 PowerShell/동적 .NET 코드 실행을 제한하면 실패할 수 있으며 정책을 변경하거나 우회하지 않습니다. 실패·취소 후 일부 출력이 남을 수 있습니다. 결과 창의 대상 경로를 확인하세요. 자동 재시도·자동 삭제는 하지 않습니다.
- 다운로드 출처 `Zone.Identifier`를 압축 결과 및 해제 파일에 유지하며, 실패하면 성공으로 표시하지 않습니다. ZIP은 일반 파일 내용·이름·폴더 구성을 보관합니다. ACL, 다른 별도 데이터 스트림 등 Windows 고유 메타데이터의 보존 수단은 아닙니다.
- 알려진 설치 위치의 **7-Zip, WinRAR, Bandizip**이 있으면 앱 선택에 표시됩니다. ZIP 이외 7z/rar/tar/gz/bz2/xz/tgz/egg/alz는 외부 앱으로 전달합니다. 지원 형식과 라이선스는 해당 앱에 따릅니다. 다른 위치의 휴대용 앱은 자동 탐지하지 않습니다.
- 외부 앱은 자체 창에서 설정·진행·취소·결과를 관리합니다. 특히 WinRAR/Bandizip 해제 대상은 외부 앱에서 고릅니다. ProjectPane의 ‘전달했습니다’는 완료를 의미하지 않습니다. Windows 메뉴를 통해 다른 도구를 직접 선택할 수도 있습니다.

WSL/UNC 복사는 네이티브 식별과 접근 권한을 확인할 수 있는 실제 파일/폴더에 한정합니다. Ubuntu의 합성 폴더로 Windows↔WSL 복사, 빈 폴더·한글 이름·원본 보존, 충돌·사전 취소·부분 실패를 실행기 및 실제 앱 IPC에서 확인했습니다. 실제 마우스 드래그·클립보드 왕복은 네이티브 입력/클립보드 접근 제한으로 검증을 마치지 못했습니다. 로컬 loopback SMB 시험은 실제 원격 NAS 검증을 대신하지 않습니다. Linux에서 대소문자만 다른 이름의 복사는 Windows 충돌을 피하기 위해 거부합니다. 링크·특수 파일·연결 단절은 지원을 보장하지 않으며, 자동 갱신 불가 안내가 보이면 F5로 갱신하세요.

**같은 WSL 배포판·볼륨 안의 이동**은 기존 이동 확인 후 동일 파일/폴더를 rename합니다. 복사 후 원본을 지우는 방식이 아니므로 Linux 메타데이터를 Windows 형식으로 변환하지 않습니다. 기존 대상은 덮어쓰지 않으며, 부분 완료·결과 불명 상태는 자동 재실행하지 않습니다. 취소는 이미 완료한 이동을 되돌리지 않습니다. 최상위 링크·다른 배포판·다른 볼륨과 **Windows↔WSL 이동은 계속 지원하지 않습니다.** Linux 소유권·권한·추가 속성의 Windows 보존 수단으로 복사를 사용하지 마세요. 복사 결과 확인과 원본 정리는 별도 판단이 필요합니다. 확장 UNC(`\\?\UNC\...`) 드롭 경로는 일반 UNC로 처리하되 파일명 `%20` 등을 URI처럼 해석하지 않습니다. 구현·검증과 제한.

| `projects-v1/favorites.json` | 모든 프로젝트가 공유하는 즐겨찾기와 저장 revision |
| `operations-v1` | 파일 작업의 요청·결과·미완료 기록 |
| `logs` | 용량이 제한된 진단 로그 |

작업과 저장이 끝난 뒤 앱을 정상 종료하고, 탐색기에서 `foundation` 전체를 새 백업 폴더에 **복사**해 보관하세요. 원본이나 `.bak`, 미완료 작업 기록은 삭제하지 마세요. 이 사본에는 실제 프로젝트 파일이 들어 있지 않으므로 작업 파일은 별도로 백업해야 합니다. 아직 설정 사본을 가져오는 UI는 없으며, 수동 교체를 검증된 복원 절차로 제공하지 않습니다. 읽기 전용으로 열리는 상태라면 먼저 위의 새 프로젝트 저장 기능을 사용하세요.

문제 보고에는 사용한 빌드/커밋, Windows·WebView2 버전, 수행한 순서, 예상 결과와 실제 결과, 화면의 오류·Windows 코드를 포함하세요. 설정·작업 기록·화면에는 개인 경로와 파일명이 포함될 수 있으므로 필요한 부분만 가려서 전달하세요. 자동 진단 업로드 기능은 제공하지 않습니다.

## 확인한 환경과 남은 검증

1.4.0의 최신 검사 결과는 [대용량 복사 검증 기록](large-copy-validation-20261109.md)에 정리합니다. 아래 이전 버전의 결과는 이력이며 1.4.0의 재검증 결과를 대신하지 않습니다. Explorer 물리 입력·클립보드 왕복은 네이티브 접근 제한으로 완료하지 못했고 실제 원격 NAS도 미검증입니다. 최종 서명·설치·게시 확인은 배포 완료 기록과 구분합니다.

1.2.0의 압축·복사·지원 범위 내 이동은 기존 이슈 #1 검사 결과를 따르며 이번 버전 상향에서 전체·마우스 검사를 반복하지 않습니다. 버전 일관성·빌드·패키지 해시와 로컬 적용 상태는 1.2.0 기록에 별도로 남깁니다.

1.1.0은 집 Windows 10에서 설치 업데이트와 격리된 합성 파일/설정의 Phase 1 동작·이전 프로젝트 복원·정상 종료를 확인했습니다. 출시 기록에 결과와 초기 실패를 구분합니다. 기존 반복 메모리 FAIL/승인 예외는 유지하며 새 장시간 검사를 하지 않았습니다. 회사 Windows 11, 실제 Snap·다중 모니터 DPI·한글 IME, Explorer 물리 드래그 왕복은 미검증입니다. 사용자 클립보드를 교체하는 시험은 하지 않았습니다.

WebView2는 별도 필요하며 패키지에 포함하지 않습니다. 1.1.0 CI도 기존 계정 결제/지출 제한으로 시작되지 않았고 로컬 검사는 별도로 통과했습니다. 상세 검사 수와 실패·보정 이력은 1.1.0 출시 기록과 이전 후보판 검증 기록을 따릅니다.

## 1.5.1 파일 작업과 열 너비

- 이름·유형·크기·수정한 날짜 열의 오른쪽 경계를 드래그해 너비를 바꿉니다. 경계에 키보드 포커스를 놓고 좌우 화살표를 누르면 10px, Shift와 함께 누르면 1px씩 조절합니다. 두 번 클릭하면 해당 열만 기본 너비로 돌아갑니다. 패널별 너비는 이 앱의 WebView 설정에 보관됩니다.
- 고정 드라이브 폴더도 삭제 버튼·우클릭 메뉴·Delete로 휴지통 확인창을 열 수 있습니다. 파일과 여러 폴더를 함께 선택해도 전체 사전검증을 거칩니다. 링크·네트워크·이동식 드라이브 및 안전하게 확인할 수 없는 폴더는 거부하며 영구 삭제로 대체하지 않습니다. 폴더의 하위 항목과 경로 크기에도 안전 한도가 적용됩니다.
- 잘라내기와 이동은 기존 지원 범위에서 이동합니다. 준비 단계에서 저장소·권한·항목 수 등의 제한이 확인되면 원본을 남기는 복사 창으로 전환하고 사유를 표시합니다. 대상 경로를 확인한 뒤 복사를 누르거나 취소할 수 있습니다. 이미 접수된 이동이나 결과가 불확실한 작업은 자동 복사하지 않습니다.
- 외부 Windows 앱의 잘라내기 클립보드는 기존처럼 지원하지 않음을 안내합니다. 해당 앱에서 복사한 뒤 붙여넣으세요.

## 표시 언어 / Display language

상단의 **언어 / Language**에서 한국어 또는 English를 선택합니다. 재시작 없이 적용되고 다음 실행에도 유지됩니다. 이전 버전에서 업데이트하거나 설정이 없을 때는 한국어로 시작합니다. 설정 저장이 불가능하면 이번 실행에만 적용된다는 안내가 표시됩니다.

Choose **한국어** or **English** in the header. The language changes immediately and is remembered on restart. Korean remains the default for existing users and when no preference is saved. If preference storage is unavailable, the app shows a warning and still applies the choice for the session.

파일·폴더·프로젝트 이름과 경로는 번역하지 않습니다. Windows 셸 메뉴 및 외부 앱의 창은 해당 프로그램의 언어를 따릅니다. 날짜는 두 언어에서 동일하게 PC 현지 시간의 YYYY-MM-DD HH:mm 형식을 사용합니다.

File, folder and project names and paths are never translated. Windows shell menus and external app dialogs follow their own language settings. Both languages display dates in YYYY-MM-DD HH:mm using the PC’s local time.
