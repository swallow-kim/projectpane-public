## Phase 1 계약

- 영역 선택은 행 바깥 빈 공간(목록 오른쪽의 좁은 여백 포함)에서 시작한다. 행에서 시작한 파일 드래그를 가로채지 않는다. Ctrl은 토글, Shift는 추가이며 Esc·포커스 상실·탭/목록 변경은 취소한다. 화면 밖 항목은 기존 범위 선택 API로 확정하고 렌더링 DOM만으로 전체 선택을 판단하지 않는다.
- 팔레트는 Ctrl+Shift+P 또는 상단 버튼으로 연다. 현재 프로젝트의 열린 탭, 프로젝트 목록, 공통 즐겨찾기, 현재 탭들의 제한된 탐색 이력과 기존 탐색 명령만 사용한다. 디스크 검색·인덱스·새 런타임은 없다. 검색 결과는 최대 100개로 표시한다.
- 닫은 탭은 패널별 최근 10개·64KiB 이내의 경로/보기 설정만 보관한다. Ctrl+Shift+T로 복원하며 새로운 탭 ID를 사용하고 이전 선택은 복원하지 않는다(새 목록의 첫 항목 선택은 기존 새 탭과 동일). 목록·선택 집합·watcher를 보관하지 않는다. 없는 경로는 탭을 유지한 채 기존 오류/주소 수정/재시도 UI로 처리한다.
- 탭 보호는 **현재 작업 공간에서 닫기만 방지**하며 폴더 이동은 허용한다. 버튼과 Ctrl+W 모두 같은 규칙을 따른다. 보호와 닫은 탭 이력은 세션 내 편의 상태로, 프로젝트 전환/앱 종료 시 초기화한다. 기존 프로젝트 저장 형식은 변경하지 않는다.
- 최근 폴더도 기존 탐색 이력에서 팔레트를 열 때만 가져온다. 다른 프로젝트의 전체 디스크나 저장되지 않은 파일 내용을 읽지 않는다.
