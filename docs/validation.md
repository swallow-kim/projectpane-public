# 지원 범위와 검증

## 자동 검사

npm run typecheck, npm test, npm run build, npm run test:browser, Rust fmt/clippy 및 desktop 라이브러리 시험을 사용합니다. 브라우저 검사는 모의 IPC와 합성 목록을 사용하며 실제 파일·클립보드·Explorer 드래그 검증이 아닙니다. Chromium은 별도로 준비합니다.

Rust 파일 작업 시험은 시험 소유 임시 경로를 사용합니다. OS 정책이나 공유 조건으로 실패할 수 있으며 접근 거부를 제품 통과로 해석하지 않습니다. 설치 분기 시험과 데스크톱 관측은 부작용을 확인한 뒤 별도로 실행합니다. 실제 사용자 폴더·현재 클립보드를 시험하지 않습니다.

현재 사본의 결과는 [export 검증 기록](export-validation.md)에 기록합니다. 스크린샷·원시 로그·개인 경로가 포함된 측정 자료는 공개 소스에 포함하지 않습니다.

## 기존 기능의 한계

- 기존 실제 앱 검증은 Windows 10 x64 중심입니다. Windows 11·물리 한국어 IME·Snap·다중 모니터 DPI·실제 Explorer/클립보드 왕복은 미완료입니다.
- Windows↔WSL 복사와 같은 WSL 배포판·볼륨 안 rename 이동은 과거 합성 파일·실제 앱 IPC로 검증했습니다. 이번 export에서 실제 WSL 시험을 반복하지 않습니다.
- 외부 MOVE 기반은 시험 전용이며 제품에서 비활성입니다. Windows↔WSL 이동을 임의로 켜지 않습니다.
- 이전 제품의 연속 8시간 기능 검사는 통과했습니다. 이번 사본이나 후속 변경의 새 8시간 통과를 의미하지 않습니다.
- 일반 4폴더·총 1만 항목은 약 235 MiB였으나, 10만 항목 폴더 반복 탐색 후 265~289 MiB로 250 MiB 목표를 초과한 기록이 있습니다. 부하 조건이 다르며 대용량 반복 메모리 문제는 알려진 이슈입니다. 확정적 누수 입증이나 메모리 목표 전체 통과로 해석하지 않습니다.
- 충돌·실패·취소·부분 성공·불명 결과를 구분합니다. 취소는 Undo가 아니며 불명 작업은 자동 재실행하지 않습니다.

설치 수명·지원 OS·네이티브 입력·배포 고지 검증은 빌드와 구분합니다. 과거 비공개 CI의 결제 제한은 코드 실패나 공개 CI 성공으로 해석하지 않습니다. 설치·보안 정책 변경·새 장시간 관측은 export 검사에 포함하지 않습니다.
